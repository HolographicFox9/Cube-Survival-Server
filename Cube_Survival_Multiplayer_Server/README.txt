CUBE SURVIVAL - LOCAL MULTIPLAYER STARTER

1. Install Node.js 20 or newer from https://nodejs.org/
2. Open a terminal in this folder.
3. Run:
     npm install
4. Run:
     npm start
5. Leave that terminal open.
6. Open Cube_Survival303_online_multiplayer_starter.html
7. On the Home screen choose Online.
8. Keep the address as:
     ws://localhost:2567
9. Start the game.
10. Open a second tab/window and repeat to test two players.

ANOTHER COMPUTER ON THE SAME WI-FI:
Use the server computer's LAN IP instead of localhost, for example:
     ws://192.168.1.23:2567
You may need to allow Node.js through your firewall.

IMPORTANT:
localhost always means "this computer". Other computers cannot use your localhost address.

HOSTL Game 651 / Server 579 / Rules 603

This build adds:
- Real Clouded Leopard vector assembly from the supplied non-ref SVG parts for Baby, Adult, Boss, Super Boss, and Big Momma, including the supplied sleep skins. Ref files were used only to measure assembly.
- Unique harvestable biome resources:
  Forest: Wild Herb, Tree Resin
  Desert: Cactus Fiber, Sandstone
  Arctic: Ice Crystal, Frost Berry
  Mountains: Iron Ore, Mountain Quartz
  Rain Forest: Jungle Vine, Jungle Fruit
- Unique materials appear in the run inventory.
- Moonmarked Forest Warden can no longer be blocked by the ordinary Hostl population cap and now spawns roughly 540-780 world pixels from an active player, with spawn-area clearing and the existing minimap marker.
- Performance: Clouded Leopard SVGs are external cached assets; no ref art ships in the renderer; biome resources use the existing static spatial grid; generic biome filler was reduced so the unique-resource pass only modestly changes total static entity count.

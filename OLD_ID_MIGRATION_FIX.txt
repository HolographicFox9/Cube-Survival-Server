HOSTL Server 529 / Game 601

Fixes Google login for accounts that existed before numeric player IDs.

The server now:
- rebuilds Google-sub -> HOSTL-ID mappings from each account record
- repairs stale/missing lookup mappings automatically at login
- can recover a unique old account by exact Google email if its googleSub was missing
- preserves old IDs only as hidden migration metadata
- reissues the login session using the new numeric HOSTL ID

No new Render environment variables are required.

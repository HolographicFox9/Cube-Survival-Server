HOSTL SHOP POPUP + HOME CLEANUP — SERVER 572 / GAME 644 / RULES 601

Changes in this build:
- Removed the large illustrated panel/cube behind the Home player-name, Play, starter-pet, and multiplayer controls.
- The Materials Shop right column is reserved for the shopkeeper only.
- Clicking a material opens a separate item-description popup with icon, rarity, description, owned count, price, and Buy button.
- Material Shop buttons no longer physically shift on press/hover, preventing the twitchy/jumpy feel.
- Purchase reveal was moved above the Shop modal (the old z-index left it hidden behind the Shop).
- Purchase reveal lasts exactly 2 seconds.
- After a successful material purchase: item-description popup hides -> purchase reveal shows for 2 seconds -> the same item's description popup returns.
- Existing Rules 601 gameplay/security fixes are retained.
